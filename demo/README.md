# 同频 · 完整前端演示

这个独立的 `demo/` 目录复制当前产品前端的页面、组件与样式，提供聊天、待办、账号和管理后台的浏览器本地演示。原有原型 preview 与正式前端入口不受影响。

## 直接使用

- **不安装任何环境**：用 Edge、Chrome 或 Firefox 打开本目录的 **`index.html`**。JavaScript 和样式已包含在这一个文件中。
- **Windows 推荐入口**：双击 **`start-demo.cmd`**。存在 Python 时启动 `http://127.0.0.1:5178/` 静态页面并打开浏览器；没有 Python 时直接打开 `index.html`。它不会安装依赖、启动应用后端或创建正式数据库。
- **命令行 / Linux / macOS**：在本目录运行 `python serve.py`（或 `python3 serve.py`）。端口占用可改为 `python serve.py --port 5179`；自动验证可加 `--no-browser`。

从其他目录调用启动脚本也可以。终端按 Ctrl+C 关闭静态页面服务；已经打开的演示页面仍能继续操作。完整应用的安装入口在发行包根目录，和本演示入口分别使用。

浏览器会按文件位置或网页地址隔离演示数据。需要稳定保存、跨标签页演示时，建议固定使用同一个静态页面地址。隐私模式、禁用存储或更换目录/端口时，原演示记录可能不可见。

## 数据与模拟范围

- 所有业务请求由页面内的演示适配层处理，不建立真实 HTTP API、WebSocket 或 EventSource 连接。单文件的 CSP 同时禁止 HTTP(S) 连接；静态服务器只提供 `index.html`。
- 人物、聊天、资料、任务和管理状态使用 `tongpin-demo.state.v1`；附件与离线待发使用专用的 `tongpin-demo.*` / `tongpin-demo-*` 存储空间。恢复初始数据只清理本演示的数据。
- 消息提示音可实际播放，默认开启；在“设置 → 浏览器通知”中调整开关、音量或试听，设置保存在本机当前演示账号。首次打开后先点击页面一次以启用浏览器声音，页面关闭后不会继续响铃。
- 监控指标、病毒扫描、系统通知授权、定时任务和服务器备份属于演示。通知设置不会申请操作系统通知权限；关闭浏览器后没有后台进程继续运行。
- 下载的附件是本机选择的原文件；管理导出 / 备份 ZIP 包含演示数据及说明，**不能用于恢复正式应用**。本地演示的身份和权限用于呈现操作流程，不构成服务器安全边界。
- 复制的产品界面保留了原来的“服务器确认”等流程文案；在本目录中，这些状态均由浏览器内的模拟逻辑生成。

## 维护与重新构建

发行包已经提供构建后的 `index.html`，普通演示无需 Node.js。修改源代码时，可在仓库根目录先 `npm ci`，然后执行：

```powershell
node node_modules/typescript/bin/tsc -p demo/tsconfig.json --noEmit
node demo/tools/build.mjs
```

也可把整个 `demo/` 复制到新目录，在该目录执行 `npm ci`、`npm run check`、`npm run build`。开发模式执行 `npm run dev` 后打开 `http://127.0.0.1:5178/app.html`；独立成品入口是 `index.html`。

`source-manifest.json` 记录复制时的产品文件和摘要；`src/sandbox/` 实现本地数据、身份、网络适配、附件、任务、群管理与管理命令。正式界面样式保留，额外的演示控制样式集中在 `src/sandbox/controls.css`。重新构建会更新 `index.html` 和 `build-receipt.json`。
