# 超级管理员使用说明

## 身份和敏感动作

`/admin` 是全站后台，使用管理员账号和密码登录，并要求有效超管身份。普通用户、群主和群管理员都不会因此获得站点权限。首次超管通过主机离线命令初始化；后台保护最后一个可用超管，不能让站点在无管理员状态下被普通操作锁死。

敏感读取填写具体理由；修改先预览目标、数量、影响和当前版本，再完成二次验证执行。预览不是执行成功。列表中的版本变化、目标失权、确认过期或再认证失败需要重新查看当前状态，不要重复使用旧预览。批量任务有有界范围、进度和逐项结果，部分失败与完成不同。

## 常用模块

| 模块 | 操作及核对重点 |
|---|---|
| 概览与监控 | 观察真实时间窗、在线用户/连接、进程内存/线程、SQLite/磁盘、队列和失败；未知指标不当作零 |
| 告警 | 核对触发与恢复时间；阈值变更进入版本化配置，等待下一次真实采样 |
| 用户与会话 | 查用户、禁用/解禁、全站禁言、强制下线；在目标用户侧核对权限变化 |
| 好友关系 | 查看和处理关系，影响双方发送权；关系管理不扩大正文读取权限 |
| 群组 | 查详情、冻结/解散、角色纠正和邀请撤销；群权限与站点角色分开 |
| 内容 | 以理由限定查询范围，审阅私聊/群聊上下文，管理删除/可恢复内容恢复；敏感访问可追踪 |
| 文件 | 查看真实处理/扫描/隔离状态、配额和引用；下载仍鉴权，删除不应留下可访问旧原件 |
| 待办治理 | 查询授权的群任务，处理本人举报或明确授权的最小个人任务内容；无普通全站个人任务浏览入口 |
| 配置 | 预览、二次验证、版本冲突、当前版本和历史回滚；保留期缩短先查看影响 |
| 公告 | 草稿、定时/发布、撤回及实际用户送达状态；未执行任务不能假报已送达 |
| 举报与反馈 | 查看待处理/已处理、关联对象和理由，结案后向举报人提供实际反馈 |
| 任务与运维 | 查看执行状态、重试/取消和保留策略；取消请求不等于所有步骤已经回滚 |
| 审计与日志 | 按时间/操作者/动作/目标查记录；日志不重复保留完整聊天正文和凭据 |
| 导出、备份、恢复 | 限定范围、有界异步执行、受鉴权下载；恢复预检和隔离演练不等于切换正式库 |

## 恢复、删除与文件

管理删除的内容在保留期内可按规则恢复，已物理清除不能恢复。用户主动撤回的正文不会通过管理员“恢复”重新发布给普通用户。清理会考虑共享引用、持有文件的完整备份及任务占用，不简单按目录整批删除。

默认撤回/删除内容保留30天，审计180天，普通运行日志和同步事件30天；后台展示实际配置。消息正文不会因为同步事件到期而自动全部消失。账号注销后共享消息与非必要身份资料分别处理。

严格文件策略下，未知/未扫描不等于安全。扫描服务故障时一般文件保持隔离；先排查本地扫描适配器、日志和任务状态，恢复后按权限重试。关闭内测放行仅允许开发/测试环境，不能配置到生产环境。

## 账号人工恢复

用户忘记密码时联系管理员协助恢复。管理员按真实身份核验结果记录理由，生成受控的一次性重置凭据，要求改密并撤销旧会话；不通过不存在的邮箱假报已通知。不能因为对方知道用户名或聊天片段就自动判断拥有账号。

管理员无需绑定动态码或保存恢复码。所有管理员均忘记密码时，在部署主机停止服务后运行 `manage recover-admin`；根据中文提示确认账号、填写恢复原因、设置并确认新密码。重设会撤销旧设备会话和旧恢复凭据，并记录审计。

## 备份、导出与恢复演练

备份包含数据库一致性快照、必要附件和校验清单；默认日备份7份、周备份4份，后台可查看真实任务和清单。外部生产密钥必须由主机运营者单独备份，代码包及一般备份下载不应公开它。

导出限定有权查询的范围、条数和体积，敏感下载需管理会话且有时效，权限撤销后不可继续下载。生成文件默认24小时后清理；记录“排队”或“处理中”不能当作文件已经导出完成。

恢复先做清单、签名、文件、空间与数据库预检，再生成独立演练目录并重放当前撤权、凭据消费和删除/到期状态。结果明确 `isolatedOnly`、`activationAllowed=false`；不会覆盖运行库。正式恢复和生产切换由目标主机维护流程另行实施，必须保留当前权限状态、密钥和可回退副本。
