# 用户使用说明

## 账号、恢复与设备

新站默认开放自主注册：在登录页点击“注册”，或直接访问 `/register`，填写用户名、昵称、密码、确认密码和图形验证码，阅读并同意当前服务条款后创建账号。用户名以字母开头，4–24位字母、数字或下划线，大小写不区分；昵称1–32个字符。密码8–128字符，不会自动去除首尾空格。注册成功后直接进入应用，地址会切回首页 `/`，无需生成或保存恢复码。从注册入口登录已有账号、或已登录时再次访问注册入口，也会回到首页。

超级管理员可以随时切换开放、仅站点邀请码或关闭注册。已有配置继续生效；关闭时不能自行注册，邀请模式需要有效站点邀请，群邀请不能替代站点邀请。验证码错误或过期后使用新图片再提交，用户名占用等错误会在表单中提示。

正常登录无需验证码。同一网络来源对同一用户名连续5次用户名或密码验证失败后，页面才出现图形验证码；这时即使密码正确也必须填写有效验证码。登录成功后计数清零，连续15分钟没有密码失败也会解除挑战。刷新、换标签页或更改用户名大小写不会清掉服务端记录。原有请求频率限制继续生效；管理员同样使用账号和密码登录；找回密码使用管理员核实后提供的一次性重置凭据。

登录后通过“个人资料”修改昵称、简介和头像，通过“账号设置”管理隐身、阅读回执、免打扰、设备与安全选项。设置按分类展示当前面板，窄屏使用分类选择；切换分类时保留尚未提交的输入。设备列表可撤销其他会话。改密码、查看敏感凭据和注销等操作需要再次验证；敏感子弹窗处理完成前，外层设置不能绕过确认直接关闭。会话被撤销/过期时会回到身份入口，未完成操作应核对当前状态后继续。

忘记密码请联系管理员。管理员核实身份后，在后台用户详情中选择“人工重置密码”，填写理由并验证自己的密码，获得一次性重置凭据后交给账号本人。本人在登录页选择“忘记密码？联系管理员”，填写账号、管理员提供的重置凭据、新密码及图形验证码即可重设密码；重置成功会使旧会话失效。无需注册时保存恢复码，也不要求动态码或第二因素恢复码。旧版恢复码不再用于找回密码。首位管理员忘记密码时，可停止服务后在部署主机运行 `manage recover-admin`。

## 好友与聊天

在联系人中按用户名查找并申请好友，对方可以接受、拒绝或取消待处理申请。互相申请按当前状态处理，重复点击不会建立两个私聊。删除好友或屏蔽后不能继续发送，重新获得权限前旧待发不会冒用新权限自动成功。

选择会话输入文字，Enter发送，Shift+Enter换行；中文输入法组合过程中Enter用于候选确认。已送达回执代表服务器提交成功；“待发送”或“结果未确认”需要查看本机待发中的真实状态。对方正在其他页面、打开任务详情或未看到消息时，不会因为后台取到数据就把消息记为已读。

鼠标移到消息气泡时，侧边出现“三”菜单：自己消息在左侧，对方消息在右侧。点击可转为待办、引用回复、收藏、复制文字、举报或在规则允许时间内撤回；点击空白处或按 Esc 关闭。键盘可聚焦菜单入口，触屏可直接点击。消息反应和内置表情选择入口已移除。群成员提及仍可从输入区使用。超时或失权时按钮可能不可用，服务器仍会重新检查权限。回复中的原内容被撤回、管理删除或失去权限后显示不可用，后续回复本身保留。搜索和文件列表只显示当前有权访问的数据。

消息提示音默认开启、音量为40%，在“设置 → 浏览器通知”中可开关、调节音量或试听，立即生效并按当前账号保存在本机浏览器。首次打开后先点击页面或按键一次以启用浏览器声音；未启用声音前和重新连接时的旧消息不会补响。前台、后台收到他人的实时消息均可提示，自己的消息、历史消息及编辑消息不响铃；免打扰、会话静音和仅提醒提及优先，连续消息会合并响铃，同一浏览器多开页面会协调避免重复提示。提示音无需系统通知授权，关闭页面后不会继续响铃。

“收藏”有独立导航入口，打开后加载本人有权访问的收藏；窄屏从“更多”进入。消息搜索可以限定当前会话或全部可见会话，点击结果定位回聊天。搜索、收藏及资料弹窗切换不会代替发送聊天编辑器中的未提交草稿。

## 图片与文件

通过输入区选择、粘贴或拖拽图片/文件，再发送。GIF 在发送前、聊天记录及放大预览中直接播放动画，不再显示“本机准备”或静态预览说明；失败和失去访问权限时仍会显示错误。默认图片最大10MiB、普通文件25MiB，每条最多6个附件且总计50MiB；实际以站点当前配额为准。额度满、扫描不可用、传输中断或权限变化会显示真实错误，不能把“处理中”当成可下载。

生产一般文档/压缩包经过严格处理；扫描器不可用时会隔离，管理员不能通过普通界面把未扫描内容伪装成clean。图片预览与下载仍需要当前会话权限，退出群或被屏蔽后旧地址不能绕过权限。重新登录同一账号并恢复网络后，可以在待发中明确重试或取消仍未确认的项。

## 断网与本机待发

本机待发和草稿保存在当前浏览器，按账号隔离，并受数量/时间/体积限制。断网刷新后可看到“离线”状态下的本人本机内容，缓存身份不代表已认证服务器会话。恢复网络后先重新核对账号与权限；重试复用同一个消息标识，避免已提交消息再次生成。

同一会话按保存顺序投递。如果前一条失败，后面的消息会显示“等待前一条失败消息处理”，聊天页也会提供“处理本机待发”入口。可以重试的失败项可点“重试”；旧权限已失效、消息标识冲突或保留期已过的项不能直接重试。需要保留内容时先点“复制到编辑器”，再对原失败项点“停止本机重试”，后续消息才能继续。复制只保留输入，不会发送或移除原条目；确认原消息实际状态后再决定是否发送复制内容。

完全断网后刷新需要此前已成功加载首页且离线缓存准备完成。首次访问或浏览器尚未完成缓存时，仍需先联网打开应用；离线页可用不代表服务器身份仍然有效。

退出登录时按提示选择保留或删除本机待发/草稿。换账号不会显示另一账号的待发，保留不代表服务器备份。清理浏览器数据、换浏览器或换设备会影响本机草稿；发送中取消只停止后续重试，不能承诺撤回服务器已经提交的消息。超过保留期限的项停止自动发送，需要本人处理。

## 群组

建群者为群主，可邀请已有好友或创建有限次数、有限有效期的邀请。收到邀请仍需本人确认，待审核申请由有权限的群管理者处理。群邀请/申请页显示当前成员状态，历史“曾获批准”不保证现在仍在群中。

群主、群管理员和普通群员拥有不同权限。禁言、移出、角色变化和解散以服务器最新状态为准。离开后再次加入形成新的成员期，聊天历史按本次加入范围读取。群主需先转让或解散群才能完成相关退出/账号注销流程。

## 待办

进入待办创建个人任务，或在有权限的群中创建群任务；标题、说明、优先级、负责人、检查项、日期和时区都可以按权限维护。领取采用版本检查，同时领取只有一方成功，另一方需查看最新状态。标完成但仍有未完成检查项时，需要明确确认。

桌面群聊天右侧的待办面板显示当前群的任务进度和未完成项，可打开详情、查看全部，或点击“创建群待办”。此入口会预选当前群和群共享范围；通用待办新建入口默认个人任务。保存前仍可核对表单中的可见范围与目标群。个人任务额度已满不应阻止有权限的群任务创建。

待办工作台提供状态筛选、更多筛选、列表/看板和任务空间。通知偏好、默认时区、个人清单与标签、群创建策略放在待办设置中；保存偏好后关闭设置。新默认时区只影响新建任务，已有任务保留原时区。

群任务的当前摘要对现成员可见，包括加入前已创建的任务；评论和活动只显示本次成员期有权看到的部分。来源消息仍独立按聊天权限检查，不能因任务可见而读取加入前的聊天。移出群、冻结或删除后，旧详情、卡片、通知和联网复核内容会失效。

消息转待办会重新检查来源，再要求确认。实时卡片反映当前任务及权限；静态副本只包含当时明确选择的字段，后续不随原任务更新。个人任务复制到群是新的任务，确认公开范围后执行，不会自动公开个人说明、检查项和历史。

离线任务草稿不会自动提交。联网后点击复核，比较服务器最新内容和本人草稿，确认后采用当前版本；失权、删除或版本变化会使旧确认无效，但本人的本机输入继续保留。不要将“离线草稿已保存”理解为服务器任务已更新。

任务标签、个人清单、关注/收藏、评论、提醒和看板属于增强能力，受站点功能开关及当前权限控制。提醒按任务日期/时区规则生成，修改日期、取消任务或移出群会撤销不再有效的提醒；站内通知不等同于浏览器关闭后的系统推送。

## 数据与注销

超级管理员可受审计地审阅私聊、群聊及附件。普通用户没有全站导出或管理权限，个人待办也不会因此变成全站公开。注册说明和设置中的注销说明列出真实保留规则。

注销会立即撤销会话并进入30天冷静期；按恢复流程可在到期前取消。已发送的共享聊天不会因为注销就从所有人的历史中消失。到期后清除非必要个人资料与凭据，显示匿名/已注销身份；已删除/撤回内容、文件、备份和审计按站点相应保留规则处理。
