## 测试分层和证据

每里程碑维护唯一 check_id、受测源码/锁文件/配置指纹、真实服务标识、OS/浏览器、隔离数据、执行步骤、预期/实际、日志和截图。有效证据可复用；代码/环境/权限/数据改变才使相关项失效。设计包 set_content 原型结果仅作设计参考。

| 层 | 核查对象 | 真实环境要求 |
|---|---|---|
| 静态/单元 | Python/TS语法类型、领域规则、缓存边界、长度/格式一致性 | 合适的临时fixture；不能替代网络 |
| 数据/迁移 | 目标Python sqlite3、WAL/事务/约束、并发、checksum、持久jobs | 磁盘SQLite临时目录与重启，不只:memory: |
| HTTP/Socket.IO集成 | Cookie、Origin、CSRF、真实WS升级、service共用、权限/幂等 | 真实Uvicorn服务，至少两个身份；不能只调用Flask test client |
| 浏览器E2E | 注册、好友、群、断网、上传下载、emoji、通知、设置 | 独立账号和browser contexts，真实HTTP来源/Cookie/IndexedDB |
| 故障/运维 | kill、丢ACK、磁盘满、DB忙、租约、备份/恢复、脚本 | 独立可丢弃数据目录，禁止正式库/用户文件 |
| 平台/体验 | Windows/macOS/Linux；Chromium/Firefox/WebKit/真实手机 | 每项单列实际结果，模拟IME/手机视口不能当真实设备输入验收 |

M8按 design package handoff/ACCEPTANCE 的 A01–A08、B01–B05、C01–C10、D01–D11、E01–E08、F01–F09、G01–G09 逐项对应证据，并增加 [全站超管 SA01–SA14](M0_SUPER_ADMIN_SCOPE.zh-CN.md) 清单。M1–M7及M7-Admin完成前不运行完整产品验收，也不以独立验收要求倒推本轮全量回归。

全站后台验收必须覆盖真实监控采样/告警及恢复、全部账号/会话/关系/群组/内容/文件管理、配置版本与运行时生效、公告、超管权限/最后超管保护、审计、批量任务和备份恢复。用户已确认超管可审阅私聊、群聊及附件；验收必须证明这条管理通道有效，同时证明普通用户/群管理员无法借管理接口越权，每次敏感访问有对应审计。

每个SA模块均检查页面、实际请求、持久状态/运行状态和前台可见结果，不能以有菜单、静态指标或接口返回200抵扣。复测包含管理权限执行中被撤销、会话过期、网络断开、部分失败、重复点击、重启后结果和筛选/分页一致性。

初始负载只作测量：100连接、5群、50活跃发送者、总10文本/秒持续10分钟，另做文件混合；记录硬件、Python/SQLite、数据库规模、ACK p50/p95/p99、RSS、线程/队列长度、DBbusy、重复/丢失与恢复时间。同机条件p95<500ms是目标，不是未测容量承诺。

## 用户追加的 UX-POST

触发条件：M8真实产品验收和M9交付准备均完成，流程进入正式交付之前，才另起新的 Astra 完整功能测试子智能体。该时点由用户2026-09-11明确追加；不能在中间开发阶段提前启动。该步骤在本任务内完成，不创建新侧边栏任务，不复用已经做验收的角色充当“另外起一个”。

模型要求：gpt-6-astra，思考等级继承主智能体当时实际等级；使用完整上下文继承或经过验证的同等级参数，记录 requested/actual。注册 browser-debugger 的固定 low 等级不满足这个要求，不能用它替代。无法确认等级或工具不可用时明确受阻，不静默降级。

工具要求：用户指定 browser-use。应核对当时可用的 Browser Use 浏览器能力、目标页面及执行权限，再操作真实界面；Python同名库未安装不等于应用内能力缺席。目前 Edge 与内置浏览器的控制连接均未读取到页面，本轮未启动体验测试。不得换成静态图片、同页mock或接口报告并称已完成此项。

执行数据：独立测试DATA_DIR/UPLOAD_DIR、至少8个隔离测试身份，覆盖群主、群管理员、群员、好友、陌生人/已退出者、两个超级管理员及被撤权的管理身份；使用独立浏览器会话。准备合成的私聊/群聊内容、附件和可恢复备份，用于全站审阅、审计、最后超管保护及容量/断网场景；禁止正式账号/聊天/生产数据库。测试账号建立不得依赖正式包内固定密码或验证码答案。

体验路径至少包括：

1. 注册、验证码错误/过期、恢复码保存、退出/登录、恢复、改密、设备撤销；真实错误能否理解和恢复。
2. 查好友、申请/交叉申请/拒绝/删除/屏蔽，建立唯一DM、互发、多设备、未读与真实阅读。
3. 发送者断网后刷新、同账号重登、网络恢复、安全重试；接收者关闭后补收；换账号和多标签页不串数据。
4. 建群、好友邀请、邀请链接/过期/审核/撤销，三个角色能做什么；禁言/踢出/再入/转让/解散及旧链接失效。
5. 图片选择/粘贴/拖拽/上传/预览/真实下载；文件取消/重试/限额/配额满/失权；下载字节一致、服务重启仍可读。
6. emoji中英搜索/分类/肤色/最近/ZWJ；回复、提及、reaction、撤回、收藏、搜索；不能从旧引用泄露失权内容。
7. 好友上线提醒、隐身/屏蔽/免打扰、站内通知、浏览器通知拒绝；不伪造后台已读或关闭浏览器后的推送。
8. 桌面、平板、320/390手机宽度；返回/抽屉、长消息、滚动锚点、键盘焦点、Escape、中文IME、软键盘与错误空态。
9. 超管身份与安全：初始化/登录、第二因素与恢复、管理员清单/权限、再认证、最后超管保护、会话撤销；普通用户与群角色不能获得站点权限，已撤权浏览器不能继续读取/订阅后台。
10. 全站监控：实时/历史概览、在线与连接明细、进程/磁盘/数据库/队列、错误/延迟、阈值告警和恢复；模拟受控故障后核对真实指标、时间窗口和未知状态。
11. 用户/会话/关系/群组管理：查询、筛选、详情、封禁/全站禁言/解封、强制下线、关系解除、跨群处置、群冻结/解散、角色纠正和邀请撤销；同时在另一普通用户浏览器检查影响。
12. 全站内容与文件：检索并审阅超管并未参与的私聊/群聊及附件、查看上下文、隔离/删除/可恢复项恢复、配额/批量处置、受控导出；读取与修改都能找到对应审计，普通下载路径不因此放宽。
13. 全站配置/公告/工单：规则和配额调整、变更预览/并发冲突、当前生效版本、需重启状态与回滚；系统公告真实送达；举报处理过程和结果可追踪。
14. 运维任务：任务重试/取消、失败恢复、维护模式、备份创建/清单、恢复预检与隔离演练；页面给出实际状态，不把部分失败、连接中断或待重启显示为成功。
15. 后台整体体验：SA01–SA14导航和详情地址、跨模块下钻、筛选/分页/返回状态、大数据列表、批量操作目标预览、键盘焦点、危险操作说明和错误恢复；同时覆盖桌面与窄屏可用性。

CAPTCHA、真实通知授权、敏感动作由当时工具的明确边界处理；不得在产品中留测试后门。工具不能代表用户完成的交互列为人工补测，并清楚区分生产逻辑与隔离fixture。
