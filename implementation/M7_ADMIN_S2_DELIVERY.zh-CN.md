# M7-Admin S2：内容、文件、举报与站点策略

本批落实SA07–SA10的四个页面及真实API：全站消息审阅与处置、文件元数据与受控读取、举报反馈和关联处置、版本化配置与站点邀请码。SA07受控批量导出、SA08实际空间清理与SA11–SA14仍在S3接入。完整后台、M8、M9及用户指定最终体验检查尚未完成。当前本批定向验证与第10轮浏览器结束，进入冻结提交和独立代码审查。

敏感读取包含理由、操作者、对象、时间、请求ID与结果审计；正文与敏感查询词不重复写入审计或页面URL。全站审阅独立于普通好友/成员身份，普通用户查询和下载继续执行原有权限。已到保留期限的数据即使清理任务尚未运行，也不能继续作为可审阅/可恢复内容返回。

文件管理使用独立治理状态，隔离和撤销不改病毒扫描结论。原件、缩略图、普通绑定和头像均检查当前状态；文件列表明确扫描状态、治理状态、配额和暂不能清理的原因。普通聊天在限制到达后立即移除打开的预览、禁用下载，并阻止跨越“限制后又解除”的旧下载结果落地。受控管理预览通过带审计的POST二进制接口加载内存Blob，关闭即释放临时地址。

举报认领、驳回、重开和处理保留状态、操作者和反馈。关联处罚只允许工单已知对象，预览同时固定其状态；关联处置和工单反馈同事务保存，重复操作ID不重复处罚。配置页面提供28项实际生效字段、中文分区、差异预览、并发版本检查与回滚；部署密钥和生产扫描底线保持只读。首次策略修改保存初始版本，回滚创建新版本而不覆盖历史。站点邀请码单次领取与实际到期分开显示。

## 第10轮真实Chrome

独立DATA_DIR与随机两名超管、三名普通账号；前置真实领域服务生成一段含图片和引用的私聊、一个举报及群成员资料，准备会话全部撤销。浏览器从实际验证码页面登录，管理账号提交密码和TOTP；后续管理动作均经页面预览、密码/独立第二因素、固定操作ID执行。没有修改正式数据。

1. 超管读取自身并非参与人的私聊上下文。隐藏后另一账号原文与图片消失，引用显示不可用。初次恢复暴露引用卡片旧状态；修复构建后再次隐藏/恢复，普通页面原文、图片和现有引用无需刷新一起恢复。最终工单处理又隐藏该消息，数据库保留与工单状态一致。
2. 管理受控预览实际加载64×48图片Blob。普通账号打开图片后，管理隔离使预览关闭、下载禁用并显示服务端理由；旧文件URL返回403 `FILE_RESTRICTED`。解除后按钮恢复，浏览器实际读取161字节，SHA256与服务器元数据一致。此项没有宣称操作系统另存为验收。
3. 页面处理举报并选择隐藏关联消息，命令成功一次；举报者收到通知，打开“我的举报”看到已处理状态和本次准确反馈。
4. 页面把消息上限4000改成3，普通账号通过聊天发送4字消息后明确失败，提示当前3字限制。后台比较初始版本0并回滚，运行版本升至2；同一条失败待发手动重试后变为已发送，数据库只有一条。
5. 页面创建一次站点邀请码，实际生成后的5分钟领取提示与1小时有效期分开显示。领取一次后隐藏，明文节点和再次领取按钮均消失；localStorage/sessionStorage无相关字段。320宽对话框在视口内。实际邀请码注册/撤销由后端专项覆盖，本轮未另注册浏览器账号。
6. 设置页28个字段在320/390/768/1024/1440/1920宽度均无整页横向溢出；320截图与管理受控预览截图已查看。其他三页的真实筛选/详情/操作在本轮桌面窗口使用；不声称每个页面均做了全宽度组合或物理手机检查。

主操作初期使用`index-BRqVrKyB.js`；引用修复后的普通页面与后续管理页面使用`index-DKYBp64i.js`。同轮重启隔离服务以载入初始配置快照修复，保留同一数据库和随机凭据，内容处置与举报记录仍可读取。完整跨平台或生产扫描服务不由本轮证明；图片扫描状态明确为封闭测试允许的`not_scanned`。
