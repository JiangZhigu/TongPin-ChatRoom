# M7-Admin S3：公告、安全、审计与实际运维

SA11–SA14已实现真实页面、权限、持久任务和归档处理，并完成第11轮隔离Chrome定向检查。本批进入冻结提交与独立代码审查；尚不表示M8、V3、三平台或最终独立体验验收完成。精确输入与接口见[S3契约](M7_ADMIN_S3_CONTRACTS.zh-CN.md)。

公告在提交时固定有效接收名单，持久分批发送，展示实际送达人数；定时任务执行时再次核对发起管理员。普通账号从通知打开系统公告，撤回事件会清除正在查看的正文。管理员邀请必须由本人验证密码、绑定真实TOTP并保存独立恢复码；管理撤权和因素恢复清除旧授权，最后一位可用管理员由事务保护。本机 `recover-admin` 维护入口要求实例停机锁、核验理由、新密码和动态码，不提供远程后门。

审计和运行日志支持操作者、对象、动作、结果、时间、请求与任务ID筛选。运行日志只保留脱敏错误代码、路由模板和关联ID，30天/10,000条有界清理；不采集密码、Cookie、恢复码、请求正文或查询参数。审计按当前180天策略保留。

受控导出固定筛选目标、条数和字节预算；只有原管理会话可在24小时内下载，每次下载重新核对当前权限及所有内容/附件状态。备份下载要求新的行动绑定再认证。二进制读取最长10分钟且可取消，普通JSON请求仍为15秒；页面只在字节和校验通过后交给浏览器，不把交接提示写成操作系统已经保存。

完整备份使用在线SQLite快照、实例谱系、数据库完整性/外键检查、归档和逐文件SHA-256及签名清单。备份期间持有文件清理保护；取消、撤权、失败与进程恢复均有真实终态。恢复演练只在私有新目录执行，覆盖当前权限、凭据消费、成员加入期和删除状态，重放到期清理并废止旧设备，再验证数据库和剩余文件，明确标记不可直接激活。每天UTC 00:00计划备份，按最近7份日备份和4份周备份保留；同盘备份的故障域限制必须由真实部署处理。

清理任务只访问经过验证的私有目录，受引用、正在执行的备份和有界批次约束；孤儿检查只识别本应用生成的文件名，未知文件不删除。过期归档回收避免在大文件删除期间长期占用数据库写锁。后台同时最多20个等待/运行的运维任务；普通任务和长运维任务使用独立处理器，取消/权限检查贯穿处理及最终提交。
