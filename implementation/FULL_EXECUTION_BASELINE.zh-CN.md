## 1. 一次确认的完整推荐方案

### FE01 工程、界面与基本功能

- Python + Flask 后端、SQLite、Windows/macOS/Linux 进程内缓存、单实例常驻服务和本地持久磁盘；不采用 Vercel。这些用户底线已确定。
- React + TypeScript + Vite 前端；Flask HTTP + python-socketio ASGI + Uvicorn；项目根 .venv、uv.lock 与前端 package-lock.json；依赖的小版本、内部目录和执行器等细节由主智能体结合实测确定并记录。
- 保留同频浅灰浅蓝聊天布局、桌面三栏/详情栏和手机单列；全站后台使用独立 /admin 入口。交付中文界面，不引入额外全站多语言工程。
- 完整交付账号、个人与安全设置、好友私聊、群和三级角色、邀请/审核、上线提醒、接收者离线补收、发送者断网队列、真实图片/文件、emoji、引用/@/reaction/撤回/收藏/搜索、草稿/通知/未读及响应式交互。
- 正式构建中不存在模拟认证、客户端验证码答案、假上传、定时假 ACK、固定人数/账号。开发和测试 fixture 与正式入口严格分开。
- 首期范围排除 E2EE、音视频、原生移动 App、公开群目录、付费系统和浏览器关闭后的 Web Push 保证；保持原范围，不擅自删减已要求的聊天或后台功能。

### FE02 业务默认值

整体采用 [C2 完整默认值表](M0_RISKS_AND_DECISIONS.zh-CN.md)，作为可配置的首期基线；硬性的权限和数据一致性不允许后台配置绕过。关键规则如下：

| 类别 | 推荐默认值 |
|---|---|
| 注册与普通账号 | 图形 CAPTCHA，不接短信/邮件；8 组一次性恢复码；密码 15–128 码点；登录名 4–24 位，ASCII 字母开头 |
| 私聊 | 成为双向好友后可新增消息；删好友后旧历史可读；屏蔽阻止新增消息与上线提醒 |
| 群与邀请 | 每群 200 人、每人最多 20 个活跃自建群；默认管理员创建、需审核、24 小时/10 个名额；群邀请不能替代注册准入 |
| 历史可见性 | since_join：只读本次加入期之后的消息；退群/被踢立即失权，再入不恢复旧期；下载/引用/收藏/搜索同样检查 |
| 群主转让 | 受让人接受、24 小时过期；成功后原群主降普通成员 |
| 消息/离线 | 正文最多 4,000 码点且 UTF-8 不超过 16 KiB；本机文字队列 100 条/7 天；离线附件合计 50 MiB |
| 附件/空间 | 图片 10 MiB、文件 25 MiB；每条最多 6 件/合计 50 MiB；用户初始配额 1 GiB，磁盘高水位 90% |
| 提醒/已读 | 上线提醒逐好友默认关闭；私聊已读可关，群不显示虚构全员已读；浏览器通知由用户主动授权 |
| 撤回 | 本人 2 分钟内可撤回；管理处置与用户撤回分别记录，前台留墓碑 |

会话时限、验证码消费、文件白名单、游标、缓存及备份等其余细节按完整 C2 表执行，不另设逐条批准。主智能体可优化内部技术参数；改变群历史、身份权限、数据生命周期等对用户可见的既定语义需要作为实际范围变更处理。

### FE03 全站超级管理员与账号恢复

完整 SA01–SA14 及私聊、群聊、附件审阅权已确定，敏感访问必须留审计。其余推荐规则一并确认：

- 超管必须使用密码 + 验证器 TOTP 动态码；提供独立的一次性恢复码。普通用户首期不交付另一个可选 2FA 功能，但保留既有密码/会话/恢复码保护。
- 无固定超管账号或密码。正式首次初始化由部署者在受保护的初始化流程中设置；开发/验收使用隔离随机身份和临时密钥，不产生生产凭据。
- 丢失密码及恢复码时，允许超管在人工核验后生成一次性重置凭据。记录核验理由和结果，强制改密、注销旧会话，并向用户可达的站内安全记录反馈；不承诺向不存在的邮箱发送通知，不提供用户名自动找回后门。
- 普通用户、群主、群管理员不获得站点权限；保护最后一个可用超管。超管自身第二因素丢失时使用恢复码或其他有效超管的受审计恢复流程；全部管理员凭据丢失时只允许部署主机上的受控维护恢复，不留远程秘密口令。
- 人工核验所需证据由实际运营者判断并记录，不能以空白理由一键冒充核验；开发测试只用合成案例验证流程。

### FE04 数据保留、删除、恢复与注销

这些是本次提出的统一默认值，确认后落实到数据库、后台配置、清理任务、用户说明和测试：

| 数据或操作 | 推荐处理 |
|---|---|
| 未撤回/未删除消息及关联附件 | 默认持续保存，受存储配额约束；不因 user_events 30 天而自动删掉消息正文 |
| 撤回/管理删除 | 普通用户立即失去正文及附件访问，只留必要墓碑；原内容进入 30 天管理保留期，超管敏感读取仍审计 |
| 恢复内容 | 30 天内管理误删可受审计恢复；用户主动撤回的正文不由管理员擅自重新发布给普通用户；已物理清除不得显示可恢复 |
| 到期清理 | 清理正文、可清理原件/预览/索引；被其他有效引用或正在执行的完整备份持有的文件按引用和备份一致性处理；明确显示待清理原因 |
| 审计/运行日志/同步事件 | 审计 180 天；普通运行日志 30 天；user_events 30 天；均有容量、分页和清理边界，审计不重复保存完整聊天正文 |
| 备份 | 7 份日备份 + 4 份周备份；恢复前重放删除/到期规则，避免恢复出已经失效的访问；生产独立故障域留给部署配置 |
| 用户注销 | 提供可用的本人再认证注销流程；立即撤销会话、停止账号使用，30 天冷静期内可通过恢复流程取消；群主先转让或解散，最后超管不能直接注销 |
| 注销到期 | 清除凭据和非必要个人资料，显示匿名/已注销身份；已发送的共享聊天按上述消息保留规则保存，UI 在注销前明确说明，不暗示注销等于全站擦除所有消息；用户名不直接分配给新账号 |

保留期缩短必须预览影响，不在保存配置时无提示地批量毁损现有数据。测试中的清理/注销/还原均只作用于可丢弃的独立数据目录。

### FE05 内容导出、文件开放与用户告知

- 允许有明确权限的超管批量导出私聊、群聊、附件和审计结果；普通用户无全站导出权。
- 导出需再次验证身份、填写原因、确定筛选范围和条数/大小；有界异步任务显示真实结果。生成文件以管理会话鉴权下载，24 小时后清理；权限撤销即时失效，不使用公开永久链接。
- 本地隔离测试可开放注册；交付的生产模式默认 closed/invite-only。首期完成配置开关，启用 open 仍需真实部署的运营决定，不在开发期间打开公网服务。
- 封闭内测按 C2 白名单接受附件；生产模式默认严格文件策略，未真实扫描的一般文档/压缩包隔离或拒绝，不假报 clean。实现明确的扫描适配接口、健康/未知/失败状态；默认不购买扫描服务或自动安装系统守护进程。
- 注册条款与隐私说明必须准确告知站点超管可审阅私聊/群聊/附件、敏感访问审计、数据保留和注销规则。交付可配置的条款版本/运营信息与开发环境说明；生产缺少必要运营信息时给出发布预检失败，不把原型占位条款伪装为正式已审定文本。
